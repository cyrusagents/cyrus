# Historical standalone customer runtime

The standalone service and CLI command have been removed. They are not a supported
launch path or fallback. Use the existing registered workspace runtime described
in [runtime automations v1](runtime-automations-v1.md).

Historical test-drive reports retain their original immutable source and artifact
identities; they are evidence of those revisions, not current installation guidance.
Current isolation, engineering repair, checkpoint and receipt recovery coverage
lives in the registered automation and engineering tests.
